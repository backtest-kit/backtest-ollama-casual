# Стратегия kondratyev_trading

LLM-стратегия для [backtest-kit](https://github.com/tripolskypetr/backtest-kit): читает закрытый Telegram-канал «KONDRATYEV IN TRADING» (id `-1002199975612`) через `telegram-reader`, извлекает сигналы моделью `gemma4:31b-cloud` (structured output через [json-inference](https://github.com/tripolskypetr/json-inference), **с картинками** — направление и тикер часто есть только на скриншоте) и ведёт позицию по постам автора: он сам объявляет закрытия.

Формат канала — как у vershinin_trader (каркас скопирован оттуда): нет диапазонов входа, целей-сеток и публикуемых стопов. Вход — «взял в работу» по рынку, закрытие — «закрыл!»/«тейк забрали» отдельным постом. **Два независимых LLM-пайплайна** (open/close), событийный вход без `getSignal` в схеме.

## Как работает

### 1. Поиск входа (`getOpenSignal`, прод: кеш `kondratyev_trading_open_v2`, 5m / окно 15м)

На тиках без позиции (`listenIdlePing`): скрейп окна, посты без текста и фото отбрасываются, всё окно уходит модели одним запросом (текст + `images`). Фильтра по тикеру до LLM нет — тикеры голые («BTC», «ARB»), промпт требует просмотреть ВСЕ сообщения. Схема: `{id, symbol, position: long|short|wait, reasoning}`.

Вход: только СОВЕРШЁННОЕ действие («взял в работу», «открыл», «переоткрыл»). Планы («буду набирать», «если…»), «выставил лимитный ордер», аналитика, реклама «позиций с партнёрами» — wait. Гейт свежести: пост старше 15 минут вход не создаёт. Вход по рынку `Position.moonbag`, **свой хард-стоп 7.5%** — автор стопы не публикует. Id сигнала — `<postId>-<symbol>` (пост 1721 открывает BTC и ETH одновременно — id должны различаться).

### 2. Закрытие по посту (`getCloseSignal`, прод: кеш `kondratyev_trading_close_v2`, 5m / окно 15м)

На тиках с позицией (`listenActivePing`), схема `{id, symbol, action: hold|close, reasoning}`. close: «закрыл!», «тейк успешно забрали», «фиксируйте позицию полностью», «прикрыл», «ушла по стопу». hold: перенос/установка стопа, «добавил маржи» (усреднение), «продолжаю держать», новые входы.

**Защита от устаревших close-постов** (багокласс, пойманный тестовым прогоном: позиции закрывались через минуту после входа постом о закрытии ПРЕДЫДУЩЕЙ позиции автора): листенер игнорирует close-пост, опубликованный до открытия нашей позиции — `new Date(message.date).getTime() <= data.pendingAt → return`.

Особый случай (пойман валидацией): пост «Шорт-позиции ушли по стопам… открыл позицию по ARB» — для ARB это вход, не закрытие; правило прописано в prompt_close.

### 3. Картинки — часть сигнала

- **Панель позиции биржи**: тикер и направление написаны СЛОВОМ в бейдже («Лонг»/«Шорт»), там же цена входа и TP/SL. На одном скрине бывает НЕСКОЛЬКО позиций (XRPUSDT Шорт + BTCUSDT Шорт).
- **Скриншот TradingView** с зонами и нарисованной стрелкой-сценарием при тексте «мысли/план» — аналитика, не вход.
- **Цвет цифр PnL — прибыль/убыток, НЕ направление** (шорт бывает с зелёным плюсом). Направление — только слово Лонг/Шорт.
- Посты без текста — хвосты фото-альбомов, не сигналы.

### 4. Логи (`Log.info`, человекочитаемый текст)

Топики `kondratyev open` / `kondratyev close` / `kondratyev trade` — тот же набор, что у vershinin: пустое окно, отправка N постов (M с фото), вердикт модели с reasoning, отброс кривого id, отброс устаревшего close-поста, фактические открытия/закрытия.

## Результат тестового прогона (август 2026, 4h, кеши `*_v1`)

6 входов (все short — автор в августе только шортил), 3 close-вердикта, итог −4.91% на 6 закрытиях: +4.25% XRP (закрыт постом автора), +0.30% BTC, −7.97% ETH (хард-стоп), −0.72% BTC (конец фрейма) и два минуса по багу устаревших close-постов (исправлен, см. §2). 6 сделок — ничего не доказывают; цель прогона (отладка промптов и пайплайна) выполнена. Полный протокол подключения канала — в корневом `PLAN.md`.

## Валидация промптов

```bash
node assets/validate.mjs   # из content/kondratyev_trading/
```

14 кейсов на живой модели (включая vision: направление только с фото, мульти-скрин, план vs вход, лимитка, закрытие+вход одним постом). Кейсы привязаны к id постов сентября 2026 — устаревшие обновлять через `assets/read-posts.mjs`.

## Запуск

```bash
# тест (4h)
npm start -- --backtest --ui --entry ./content/kondratyev_trading/main.test.ts --cache

# прод (5m/15м)
npm start -- --backtest --ui --entry ./content/kondratyev_trading/main.strategy.ts --cache
```

Команду запускает сам пользователь. `SYMBOL_LIST` в `config/loader.config.ts` — под монеты канала: BTC, ETH, ARB, SUI, ZEC, XRP. Смена схемы/промптов/отбора постов = новые имена кешей (`*_v3`, ...).
